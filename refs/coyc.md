# coyc.pro: реальный функционал по разделам

Боевой сайт на Next.js. Данных почти нет (0 вакансий), многое за логином, поэтому функционал удобнее всего доставать из строк интерфейса в JS-чанках страницы. Заполнять этот файл по мере работы над разделами.

## Как достать строки раздела

```bash
mkdir -p /tmp/coyc && cd /tmp/coyc
curl -sS https://coyc.pro/<раздел> -o page.html
for c in $(grep -oE '/_next/static/chunks/[a-z0-9]+\.js' page.html | sort -u); do curl -sS "https://coyc.pro$c" -o "$(basename $c)"; done
grep -l "<ключевое слово раздела>" *.js | xargs -I{} sh -c 'grep -oE "\"[^\"]*[А-Яа-яЁё][^\"]{2,120}\"" {} | sort -u'
```

Нужен доступ к `coyc.pro` в сетевых настройках окружения (в окружении `sous` он есть).

## Вакансии и резюме (`/vacancies`), проверено 24.11.2026

- **Переключатель «Вакансии / Резюме»** на одной странице.
- **Поиск:** «Поиск по названию или компании».
- **Фильтры:** город («Любой город»), специализация, опыт (Без опыта, От 1 года, От 3 лет, От 5 лет), тип занятости (Полная, Сменный, Гибкий, Вахта, Проектная), зарплата от/до, «Только верифицированные». Активные фильтры снимаются по одному, есть «Сбросить фильтры».
- **Сортировка:** по релевантности, сначала новые, сначала старые, ЗП по возрастанию и убыванию.
- **Счётчики:** активных вакансий, новых за сутки, верифицированных компаний, средняя ЗП по индустрии.
- **Карточка:** «Опубликована сегодня / вчера», «Истекает сегодня», «Срок истёк», зарплата «в месяц на руки», «оклад», «по договорённости».
- **Отклик:** только специалисты («Откликаться на вакансии могут только специалисты»). Гостю: «Войти и откликнуться». Сопроводительное сообщение. «Отклик придёт работодателю в личные сообщения. Дальнейшее общение в разделе «Сообщения»».
- **Создание:** «Заполните вакансию без регистрации, черновик не пропадёт», «Публикация после регистрации и верификации», «Для публикации подтвердите бизнес-профиль». Вакансия привязана к филиалу. Поля: название, филиал, специализация, город, график, опыт, зарплата от/до, описание, требования через запятую, точка на карте (необязательно), «Продвигать вакансию (выше в выдаче)».
- **Управление:** редактировать, удалить («вакансия исчезнет из каталога, отклики кандидатов будут закрыты»), «Изменения попадут в фид через 1–2 минуты».

## Подработки (`/gigs`), проверено 25.11.2026

- **Вкладки:** «Подработки», «Исполнители» (мастера со статусом «готов к подработке»), «Мои», «Архив» («Завершённые и истёкшие подработки появятся здесь»).
- **Подзаголовок:** «Разовые задачи на 2–12 часов и срочные подмены в детейлинг-студиях. Откликайтесь, договаривайтесь о ставке, зарабатывайте между основными сменами».
- **Поиск:** «Поиск: «полировка Tesla», «мойщик»…».
- **Фильтры:** город («Любой город»), тип работ (Мойка, Полировка, Химчистка, Керамика, Оклейка / Бронепленка, Детейлинг, Прочее), «Срочно». Есть «Сбросить фильтры».
- **Сортировка:** «Сначала новые», «Ставка: по убыванию».
- **Счётчики:** открытых подработок, новых сегодня, средняя ставка в час, городов.
- **Карточка:** оплата «за смену» или «в час», «Договорная», «по договорённости», число откликов («Пока никто»), статус «Закрыта».
- **Отклик:** сообщение («Расскажите о себе и почему вы подходите...»), «После отправки мы создадим диалог с заказчиком в личных сообщениях». Успех: «Мы создали диалог с заказчиком и отправили туда ваш отклик. Продолжите разговор в личных сообщениях: обсудите детали и ставку», кнопка «Перейти к диалогу».
- **Исполнители:** «Готов к подработке», «желаемая ставка», «Открыть профиль», «Предложение услуг». Пусто: «Здесь появляются мастера со статусом «готов к подработке»».
- **Создание:** привязка к филиалу («Сначала добавьте филиал»), «Дата смены», «Оплата за смену», «Срочно (в течение суток)», «Срочные подмены видят все мастера в радиусе 30 км», точный адрес виден исполнителю после отклика.
- **Управление:** редактировать, удалить.
