# СОУС: дизайн-правила и компоненты прототипов

Короткая выжимка, чтобы не перечитывать скил [unslop](https://github.com/heydamir/unslop) (CC BY 4.0, Damir Sokolovsky). Скил применяем **в щадящем режиме**: бренд стенда сохраняем, чистим только «нейросетевые» признаки. Информационную архитектуру, навигацию и роли скил не покрывает: это наша работа.

## Что не трогаем (визуал утверждён)
- Только тёмная тема. Светлую пока не прорабатываем: кнопка в шапке есть, но показывает «ещё в работе». Акцент `#ee5a20`.
- Шрифты: **Alumni Sans** 600–700 для заголовков страниц, крупных цифр и денег; **Montserrat** 400/500/600 для всего остального.
- Палитра, радиусы и отступы: токены в `docs/shared/sous.css` (`--bg`, `--surface`, `--surface-2`, `--fill`, `--fill-2`, `--text`, `--text-2`, `--text-3`, `--primary`, `--ok`, `--r-control` 10, `--r-card` 16, `--r-panel` 20).

## Правила (проверять на каждой странице)
1. **Убираем лишнее.** Не дублируем информацию на экране: один счётчик, одно главное действие, город задаётся в одном месте. Блоки со словами общего вида («Ответственность», «Внимание к деталям») удаляем.
2. **Один акцент.** Оранжевый только у главного действия экрана и кнопки поиска. Переключатель разделов нейтральный: активный сегмент выделен заливкой. Кнопки в карточках списка нейтральные.
3. **Без контуров.** Карточки, кнопки, поля, чипы, окна и меню отделяются заливкой (`--surface`, `--fill`), а не обводкой. Обводка только у фокуса с клавиатуры. Тонкий разделитель допустим внутри составного контрола (поиск | город) и между фактами.
4. **Тексты:**
   - длинное тире (—) не используем вообще; короткое (–) только в диапазонах чисел;
   - без восклицательных знаков и точек в коротких подписях, кнопках, заголовках;
   - регистр как в предложении, без капса с разрядкой;
   - без приветствий, рекламных слов и непроверенных обещаний; цифры и обещания не выдумываем.
5. **Цифры:** один формат денег (`salary()` в `sous.js`: «90 000–125 000 ₽», «от 110 000 ₽»), табличные цифры (`.num`).
6. **Иконки:** один набор, Tabler Icons (tabler.io/icons, MIT), стиль outline, в `ICONS` в `sous.js`. 16 px, линия 1.75 px, цвет текста. Другие наборы не смешиваем. Без эмодзи. Цветная только зелёная галочка «Проверена».
7. **Плашки:** без цветных пилюль-тегов. Статус пишем тихим текстом с иконкой (`.verified`, `.mine-tag`).
8. **Сетка:** отступы кратны 4. Одинаковые элементы одного размера. Внутри группы отступ меньше, чем между группами.
9. **Выпадающие списки и даты только кастомные:** `dd({...})` и `datePick({...})`, никаких `<select>` и `<input type="date">`.
10. **Движение:** только смена цвета на наведении и лёгкое появление окон. Без пульсаций, параллакса и масштабирования карточек.
11. **Фон шапки страницы:** мягкий тёплый градиент (`.head`), без картинок.
12. **Шапка сайта:** сплошная, не стеклянная.
13. **Без точки-разделителя «·».** Не склеиваем факты в строку через «·» (как и через «|», «/», «•»). Вместо этого:
    - **разные факты в ряд** → отдельные элементы с отступом: `.meta` (с иконками) или `.parts` (без иконок), отступ 12–20 px;
    - **главное и второстепенное** → иерархия: вторая строка, меньший кегль, `--text-3` (`<br>`, `<small>`, подпись в `.facts`);
    - **счётчик** → число отдельным приглушённым элементом: `Отклики<span class="count">3</span>`, как в переключателе разделов;
    - **внутри одной фразы** → обычный язык: запятая, двоеточие, точка, предлог («Shine&Go, Казань», «Ваша вакансия: 2 новых отклика»);
    - **пункт выпадающего списка** → третий элемент опции становится серой второй строкой: `[value, "Мастер по PPF", "90 000 ₽"]`.
    Исключение только `<title>` вкладки браузера. `tools/check.cjs` ловит «·» в тексте страницы.

## UX-принципы
- **Два клика:** любой раздел находится через группу в шапке → раздел.
- **Действие по роли:** у каждой роли своё главное действие. Нецелевым ролям одна строка подсказывает, куда им на самом деле (`.note`).
- **Вход в момент действия:** смотреть можно без регистрации, вход запрашивается на отклике, сообщении, публикации и возвращает к начатому действию (`needAuth`, `PAGE.afterLogin`).
- **Доверие рядом с карточкой:** «Проверена», рейтинг, отзывы живут в карточке, а не отдельным блоком.
- **Мобилка:** первый элемент списка виден на первом экране; фильтры и сортировка в нижней шторке; на детальной закреплена панель с главным действием.
- **Неготовые экраны:** ссылки через `pageHref("/путь")`, клик показывает подсказку, а не уводит на другой сайт.

## Компоненты (`docs/shared/sous.css` + `sous.js`)

| Что | Разметка или функция |
|---|---|
| Кнопки | `.btn`, `.btn.primary`, `.btn.ghost`, `.sm`, `.lg`, `.block`, `.icon-only`, `.done` |
| Поля | `.field > span + .input / .textarea`, подсказка `small` |
| Выпадающий список | `dd({ key, name, value, options, variant: "bare" / "compact", iconName, label })`, опция `[value, label, sub?]`, выбор ловит `PAGE.onDD` |
| Выбор даты | `datePick({ key, name, value, min, max, label })`: кнопка «Чт, 26 ноября» и календарь на русском, неделя с понедельника, «Сегодня» и «Завтра» внизу, стрелки и PageUp/PageDown с клавиатуры. Значение в скрытом поле `ГГГГ-ММ-ДД`, выбор ловит `PAGE.onDD`. Нативный `<input type="date">` не используем |
| Чекбокс, переключатель | `label.check > input + span + .c`, `input.switch` |
| Шапка страницы | `section.head > .wrap.head-in`: `.head-row` (`.tabs` segmented control из `a.tab[role=tab][aria-selected]` + действие), `h1`, `.lead`, `form.search` |
| Каталог | `.catalog` = `aside.filters` + `#results`: `.toolbar`, `.chips`, `.note`, `.list` из `.card`, `.empty` |
| Карточка | `.card`: без логотипа, акцент на заголовке: `.c-main` (`.c-title`, `.c-org`, `.meta`, `.c-desc`), `.c-side` (`.money`, `.c-actions`). Карточка человека `.card.person` с аватаркой `.tile.round` первой колонкой |
| Проверка в карточке | `verifiedMark()` или `verifiedMark("person")`: только зелёный значок с галочкой (`badge`), подсказка с заголовком и пояснением на наведении и фокусе. На детальной остаётся текст `.verified` |
| Детальная | `.detail > .back`, `.d-grid` = `.d-main` (`.panel`, `.d-head`, `.facts`, `.bullets`) + `.aside` (`.action-card`, `.org-card`), `.related`, мобильная `.mbar` |
| Метки и отклики | `.urgent` (Срочно с молнией), список откликов у владельца `.resp > .resp-row` (`.tile.round`, `b`, `.sub`, `p`, `.resp-side`) |
| Профиль | `.d-person` (аватар, имя, должность), `.status-line` (статус только в карточке действия справа, в шапке профиля `.d-status` виден лишь на мобилке), `.skills`, `.timeline`, `.gallery > figure`, `.cert` (подтверждение: `verifiedMark("cert")` в конце названия), `.rating-sum` + `.reviews > .review` (каждый отзыв карточкой: текст, внизу автор и дата; без таблиц с разделителями), `.lines` из `.org-line`, `.contact-mask` |
| Окна | `openModal(mHead(заголовок, подзаголовок) + .m-body + .m-foot)`, `closeModal()`, успех `.success` |
| Вход | `needAuth(kind, id)` → `authModal`, тексты в `PAGE.authText` |
| Уведомление | `toast(заголовок, текст, "ok" / "info")` |
| Утилиты | `$`, `$$`, `esc`, `fmt`, `salary`, `ago`, `initials`, `plural`, `icon(name)`, `route()`, `pageHref(path)`, `soon(path)` |

Новая иконка: найти на tabler.io/icons (стиль outline), скопировать пути из `<svg>` (сетка 24) в `ICONS` в `sous.js`, без служебного `<path stroke="none" d="M0 0h24v24H0z"/>`. Толщину задаёт `.icon` в CSS (2.6 в сетке 24 = 1.75 px при 16 px), атрибуты из SVG не переносим. Заливную версию (filled) берём только для точки `dot`, ей ставим `fill="currentColor" stroke="none"`. Пакет целиком: `npm pack @tabler/icons`, файлы в `icons/outline/`. Логотипы соцсетей: Simple Icons (CC0).
