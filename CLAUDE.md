# СОУС: правила для работы в репозитории

Прототип переработанной платформы СОУС (UX, навигация, роли) в HTML для GitHub Pages. Контекст заказа и договорённости: `CONTEXT.md` (читать, только если нужен контекст заказа). Дизайн-правила и компоненты: `DESIGN.md`.

## Структура
- `docs/<страница>/index.html` — страницы прототипа. Подключают общие `docs/shared/sous.css`, `docs/shared/sous.js`, `docs/shared/pages.js`.
- `docs/shared/pages.js` — все экраны и их статусы (готово, в работе). Отсюда строятся меню и панель страниц.
- `docs/<страница>/README.md` — решения, роли, user flow, открытые вопросы по странице.
- `refs/stand/` — копия исходников стенда, карта «маршрут → функция» в `refs/stand/README.md`.
- `refs/coyc.md` — реальный функционал coyc.pro по разделам.
- `tools/check.cjs` — проверка страницы: скриншоты, ошибки, тире, `<select>`.

## Как работаем
- **Новая страница:** команда `/new-page <маршрут>` (`.claude/skills/new-page`).
- **Правки:** точечно, через `Edit`. Читать только нужный фрагмент файла. Общие компоненты правим в `docs/shared/`, а не копируем в страницу.
- **Проверка:** `node tools/check.cjs <папка> "#/"`. Для мелких правок текста или стиля достаточно одного скриншота или без него, если пользователь так сказал.
- **Публикация:** коммит в рабочую ветку, затем `git push origin <ветка>:main`. GitHub Pages собирается из `main`, папка `/docs`.
- **Кэш:** Pages отдаёт файлы с кэшем на 10 минут. Если менялись `docs/shared/*`, перед коммитом обнови версию в ссылках всех страниц:
  `sed -i -E "s#\.\./shared/(pages\.js|sous\.js|sous\.css)(\?v=[0-9]+)?\"#../shared/\1?v=$(date +%Y%m%d%H%M)\"#g" docs/*/index.html`

## Интерфейс
- Точку-разделитель «·» в интерфейсе не используем: разные факты разносим отступом (`.meta`, `.parts`), второстепенное уводим на вторую строку, счётчик выносим в `.count`, внутри фразы пишем запятую или двоеточие. Подробно: правило 13 в `DESIGN.md`. Исключение: `<title>`.
- Длинное тире (—) в тексте интерфейса не используем вообще. Перестраиваем фразу, ставим двоеточие, запятую или «·» в `<title>`. Короткое тире (–) только в диапазонах чисел.
- Визуал стенда не меняем: тёмная тема по умолчанию, акцент `#ee5a20`, Alumni Sans + Montserrat. Скил unslop применяем в щадящем режиме (выжимка в `DESIGN.md`).
- Контуры у элементов не рисуем, если они не обязательны: отделяем заливкой. Выпадающие списки и выбор даты только кастомные (`dd()`, `datePick()`).
- Шапка сайта сплошная, без стекла. Фон шапки страницы: мягкий градиент, без картинок.
- Ссылки на неготовые экраны не уводят на другие сайты: только `pageHref("/путь")`, клик показывает подсказку.
