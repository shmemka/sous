# СОУС: правила для работы в репозитории

Контекст заказа, договорённости и источники: `CONTEXT.md`. Прочитать перед работой.

## Интерфейс
- Длинное тире (—) в тексте интерфейса не используем вообще. Перестраиваем фразу, ставим двоеточие, запятую или «·» в `<title>`. Короткое тире (–) только в диапазонах чисел.
- Визуал стенда не меняем: тёмная тема по умолчанию, акцент `#ee5a20`, Alumni Sans + Montserrat. Скил unslop применяем в щадящем режиме.
- Контуры у элементов не рисуем, если они не обязательны: отделяем заливкой. Выпадающие списки только кастомные.
- Ссылки на неготовые экраны не уводят на другие сайты: показываем подсказку. Статусы экранов в `docs/shared/pages.js`.

## Сдача
- Прототипы лежат в `docs/<страница>/index.html`, публикуются через GitHub Pages из `main`, папка `/docs`.
