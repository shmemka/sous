# Карта СОУС (`/sous-map`)

[Интерактивная карта](https://shmemka.github.io/sous/sous-map/#/).

## Что изменилось
- Подключена реальная тёмная карта (Leaflet + CARTO Dark Matter, работает без API-ключей) с реальными координатами точек в Москве, Казани, Санкт-Петербурге и Екатеринбурге.
- Убраны декоративные плашки доверия, `<select>` выбора города (заменён на кастомный `dd()` в строке поиска) и десятичные рейтинги.
- Список компаний слева синхронизирован с маркерами на карте и карточкой выбранной точки (перелёт к точке по клику, масштаб, авто-фокус при выборе города).
- На мобильных устройствах переключение между картой и списком через вкладки `Карта / Список`.
